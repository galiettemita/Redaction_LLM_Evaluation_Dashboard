Replace repetitive per-task chat approvals with an auditable Codex-led engineering loop for the already confirmed Redaction Lab product scope:

`PLAN -> IMPLEMENT -> TEST -> INDEPENDENT AUTOMATED REVIEW -> CORRECT -> REGRESSION TEST -> COMMIT -> INTEGRATE -> NEXT TASK`

## Required task records

Before consequential writes, Codex creates or updates a bounded task record that names the baseline, objective, non-goals, affected files/actions, acceptance evidence, review method, rollback and stop conditions. Routine engineering, related corrections, documentation, branches, commits, pull requests and normal reviewed integration are authorized when that record remains within confirmed product and safety boundaries.

Independent automated review uses a fresh reviewer context or process where available and records the exact candidate SHA. Automated research checks may verify preservation of approved semantics but cannot grant scientific validity.

## Nondelegable stop gates

Stop only affected work for paid resources without budget, missing essential credentials, legal/institutional data permission, unresolved critical security risk, destructive external actions, confirmed product-scope changes, public deployment/distribution authorization, or designated human approval of scientific scoring, benchmarks or release claims. Continue other safe independent work.

No private research data, credentials, raw model payloads or private conversation exports may enter the public repository. Unknown or unreliable truth remains null/UNKNOWN. Reference data remains structurally unavailable to prediction inputs. No automated review substitutes for designated human scientific or institutional approval.
