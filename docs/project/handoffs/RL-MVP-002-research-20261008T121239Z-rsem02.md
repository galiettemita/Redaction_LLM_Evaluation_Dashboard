## Findings

### Blocking finding 1 — overlapping/duplicate black boxes are not rejected before target creation

DEC-007 defines one visually contiguous blacked-out region that covers text as one immutable target. The Research review packet explicitly asks whether partial/multiple/overlapping occlusions are rejected rather than silently accepted.

The candidate enumerates every near-black filled page rectangle independently and appends a RedactionTarget when that rectangle intersects text. There is no overlap/duplicate/connected-component guard among candidate rectangles before target creation.

Consequences:
- Two non-identical overlapping rectangles over one hidden span satisfy the current acceptance path and become two distinct target IDs even though the visible black region is contiguous/ambiguous. Later prediction and reference alignment would treat one physical hidden region as two targets.
- Two identical rectangles produce the same deterministic target ID twice because target identity is derived from document version, page and geometry. Detection can therefore report SUPPORTED with duplicate target identities. canonicalize_redacted then encounters two same-ID marker insertions and fails its exactly-one-marker invariant rather than rejecting the ambiguity at detection.

Required correction: before returning SUPPORTED, reject overlapping/duplicate ambiguous rectangle candidates (or apply an explicitly approved deterministic connected-region rule consistent with DEC-007). For Task 2, fail-closed UNSUPPORTED is the safer change; do not silently create overlapping targets.

### Blocking finding 2 — a plausible standalone text redaction can be silently counted as artwork and produce false NO_REDACTIONS

The packet requires ambiguous candidates to fail closed or be explicitly UNSUPPORTED and forbids silent omissions/false completeness. Current logic handles a black rectangle with no intersecting extractable glyphs as follows: if _same_text_flow() finds nearby same-line visible characters, return AMBIGUOUS_TEXT_FLOW_RECTANGLE; otherwise increment ignored_artwork_count and continue.

This silently misses a plausible redacted sentence/line/paragraph represented by a black rectangle on its own line with no underlying extractable text layer and visible context on lines above/below. That case is within the product's text-passage concept, but the detector lacks enough evidence to call it artwork. The current path can return NO_REDACTIONS, which means "no supported target exists" rather than "coverage uncertain."

Required correction: when a near-black rectangle has redaction-like geometry but no occluded extractable glyphs, do not silently classify it as non-text artwork solely because same-line neighbors are absent. Add conservative layout evidence sufficient to distinguish artwork, or fail closed as UNSUPPORTED/ambiguous for standalone candidates. Preserve true remote artwork exclusion, but uncertainty must not become NO_REDACTIONS.
