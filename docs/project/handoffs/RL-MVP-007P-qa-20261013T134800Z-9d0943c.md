## QA/security findings

### Loopback binding — PASS

`launch.sh` hard-codes:

`make_server("127.0.0.1", port, ...)`

independently of environment input.

`preflight.sh` additionally rejects any `REDACTION_LAB_HOST` other than literal `127.0.0.1`.

The merged API separately rejects non-loopback REMOTE_ADDR and unsafe Host/Origin values.

No `0.0.0.0`, localhost alias, IPv6 or LAN bind fallback exists.

### HTTP framing — PASS for this local diagnostic server

The launcher uses single-process `wsgiref.simple_server`, sets a 10-second socket timeout before request handling, and inherits HTTP/1.0 response behavior.

The merged 7B body parser requires strict decimal Content-Length and bounds reads.

My independent raw-socket probe did not permit an appended second request after conflicting Transfer-Encoding/Content-Length framing.

Residual note: `wsgiref` is intentionally a diagnostic local server, not a hardened production HTTP stack. That is accurately disclosed and is not a blocker for this packet's local diagnostic scope.

### Shell injection / environment handling — PASS

Shell variables used as executable/path arguments are consistently quoted.

Port parsing occurs in Python using strict ASCII decimal checks before launch.

The launch phase re-parses the port with `int(...)` only after preflight succeeds.

No environment value is interpolated into shell source, passed to `eval`, or executed through `sh -c`.

### Path safety / storage initialization — PASS

Preflight:
- uses Task-7A `resolve_paths` / descriptor-based `preflight_directories`;
- requires a dedicated absolute data root;
- rejects source-checkout overlap and home-directory misuse;
- rejects symlinked path components;
- requires existing data root mode 0700;
- does not create the data directory.

Launch:
- binds the port **before** initializing storage or migrating SQLite;
- uses Task-7A `initialize_paths`, ApplicationStore migration locking/backups, and ArtifactStore descriptor confinement;
- sets `umask 077`.

Occupied-port failure therefore occurs before application state mutation.
